# Security Policy

## Supported Versions

Security reports are accepted for the latest released version of each Anne
Engine gem. Older versions are not actively evaluated unless they are covered
by a separate support agreement.

| Version | Security report status |
| --- | --- |
| Latest release of each gem | Reports accepted for evaluation |
| Older releases | Not actively evaluated without a separate agreement |

Acceptance of a report for evaluation does not guarantee a fix, release, or
support commitment.

## Reporting a Vulnerability

Use GitHub Private Vulnerability Reporting from this repository's **Security**
tab and select **Report a vulnerability**. Do not open a public issue or pull
request containing vulnerability details.

Include the affected gem and version, impact, reproduction steps or proof of
concept, and any known workaround. Please allow the maintainers to evaluate the
report privately before public disclosure.

Open-source use does not include a security response SLA. Unless a separate
written agreement applies, we do not guarantee a response time, fix, disclosure
date, or release. Contracted projects and customers with active support
agreements are prioritized.
